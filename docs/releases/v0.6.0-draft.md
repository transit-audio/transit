# transit v0.6.0 (draft)

Draft release notes for v0.6.0, the instruments release. Keep this file in step with what lands; it becomes `v0.6.0.md` at the tag. transit is alpha-quality software and the session format may still change, so back up anything you care about.

## Highlights

- **Breaking: the Subtractive Synth is gone and the Macro Oscillator is the default instrument.** A new instrument track now carries the Macro Oscillator (default model, 8 voices). The built-in Subtractive Synth is removed, with its panel, presets and help. A session saved with it opens with a Macro Oscillator in its place: the old synth's parameters, and the MIDI mappings, automation lanes and rack macro targets that pointed at them, are dropped, the load report says what was dropped, and the status line reads "N track(s) used the retired Subtractive Synth and now carry the Macro Oscillator". The session opens as modified so the substitution shows on save. Notes, clips, the track's mixer settings, racks and inserts are untouched, but the track sounds different until you pick a patch (#234, [ADR 0033](https://github.com/transit-audio/transit/blob/main/docs/adr/0033-built-in-instruments-mutable-instruments-port.md)).
