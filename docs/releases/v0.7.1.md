## Fixes

- Sampler: Clear pad, Delete zone, a slice marker edit that frees a pad, and a pad Slices to pads unbinds now reset that zone's level, pan, envelope, modulation and shaper settings in the same undo step, so the next sample loaded there starts from the defaults; one Undo brings the old settings back with the zone (#478).
- Sampler: a zone or slice loop given a sample the session already holds keeps the kind another Sampler records for it: a file loaded by its path stays referenced where it is, so recalling another kit releases it when nothing else uses it; a sample no Sampler has loaded yet, such as a recording, stays the session's own audio and a save copies it into Audio Files (#471).
