## Fixes

- Sampler: a zone or slice loop given a sample the session already holds keeps the kind another Sampler records for it: a file loaded by its path stays referenced where it is, so recalling another kit releases it when nothing else uses it; a sample no Sampler has loaded yet, such as a recording, stays the session's own audio and a save copies it into Audio Files (#471).
- Mixer: the main bus's INT loudness no longer includes the metronome click, so it reads the same as a render of the same program, also across tempo and meter changes (#399).
- Mixer: Mono on the main bus is grayed out with the reason on a main bus wider than stereo, where it never applied; `mix.monitor` answers the state in effect as `mono` and the stored choice as `mono_preference` (#408).
- Audio import: an MP3 whose last frame cannot be decoded imports without that frame and logs a warning, instead of being refused; a frame that cannot be decoded in the middle of a file is still refused (#297).
- Bounce: a scripted `track.bounce` or `track.commit` range may start in the bounce tail after the session's material, so a script can print only the tail; a start past the tail is refused and names the limit (#335).
- Arrangement: a move of several clips that reaches the start of the session stops all of them there with their spacing kept, where each clip used to stop at the start on its own; a protocol `edit.paste` with a negative `at`, or `midi.new_clip` with a negative start or end and no length, now stops at bar 1 too (#441).
- Clipboard: MIDI clips copied before opening another session paste without the old session's group, loop and take, and Paste no longer uses a replaced session's copied ranges (#479).
- Sampler: zones are no longer rebuilt at every bar line during playback; their synced divisions are rebuilt only when a meter change or a locate moves the bar grid (#490).
- Track presets: a track preset keeps its Sampler kit's samples by file, relative to the preset when they sit in or below its folder, so loading it into another session finds the right samples; a sample that is not found loads missing and the status line names it. This is an alpha break: a track preset saved before 0.7.1 named its samples by the old session's internal numbers, so it loads with its samples marked missing and nothing is converted: load the samples again and save the preset anew (#458).
- Sampler: saving a session no longer copies the referenced samples of a Sampler kit saved by a newer transit (which this version keeps as saved) into Audio Files; they stay where they are, as a readable kit's do (#489).
- Templates: Save As Template keeps the audio files the session's Sampler kits play, so a session started from the template plays its kits; freezes are left out, and a kit sample with no file yet refuses the template until the session is saved (#493).
- Sampler: a zone or slice loop command that is refused (an end past the file, a key-map group rule, a memory bound) no longer uses up the prepared import, so a corrected call can still use it (#491).
- Plug-ins: a CLAP plug-in that reports a processing error puts out silence for that stretch instead of the dry input, and the status line names it (#284).
- Plug-ins: shutting down no longer skips a VST3 module's exit when two plug-in threads end at the same moment, so the shutdown stays clean (#235).
- Automation: a lane on a hosted plug-in parameter that was never set by hand now reaches the plug-in, where it used to be ignored; a lane on a parameter the plug-in does not have is skipped (#296).
- Typed values: every typed value field commits on Enter or a click elsewhere and cancels on Escape, and a click elsewhere hands the keyboard back at once, so shortcuts work again (#484).
- Changed behavior: a value typed in a mixer readout or the tempo field is now applied by a click elsewhere, where it used to be discarded; Escape cancels it (#484).
- MIDI Mappings: the Range fields take one fixed width, so they line up across rows (#496).
- Macro Oscillator: the filter well draws the shaper filter's real response with room over its highest peak, its cutoff point on the curve, and a slope that fades into the floor (#428).
- Arrangement: View > Show Grid Lines hides or shows the grid lines both under and over the clips; the ruler keeps its ticks (#328).
- Changed behavior: volume and send levels set from automation lanes, MIDI Learn and send drags (also the send field and wheel) now follow the channel fader's own law, which tops out at +6 dB, instead of an older law that reached +12 dB. Existing MIDI Learn volume and send mappings therefore give a different level at the same knob position: 70 percent of travel was about -0.4 dB and is now about -6.9 dB, and the top gives +6 dB instead of +12 dB. Levels a session already stores above +6 dB are kept and play as stored, until the first edit through one of these controls brings them within +6 dB (#357).
- Audio files: saving a session, an autosave, a session bundle, a clip group file, or a 32-bit float bounce or export no longer clips audio above 0 dBFS; 32-bit float files keep every sample as it is, and only a NaN or infinite sample is written as silence. A session saved before this fix that held audio above 0 dBFS keeps the clipped audio: the original levels cannot be recovered from the saved file (#519).
- Macro Oscillator: the Wave terrain model no longer crashes the audio thread when a note change pushes its path past the edge of the terrain (for example a low note after a high one at high Timbre and Morph); past the edge it holds the terrain's last wave (#520).
