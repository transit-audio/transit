# transit v0.6.2

This is a patch for Linux plug-in editors; Windows and macOS builds are v0.6.1 with a new version number.

## Fixes

- Linux: a plug-in editor that asks the host to map its window (the XEmbed convention GTK-based editors use) now appears; before, the window opened and stayed blank (#289). Editors that map themselves keep direct keyboard focus as before.
- Linux: one and five seconds after an embedded editor opens, the log carries an `editor surface:` line (window, visual, children, timers, events) and a warning when nothing is mapped; paste these when reporting a blank editor.

See the [v0.6.0 release notes](v0.6.0.md) for the release contents.
