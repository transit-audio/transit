# E53: Controller-only MIDI recordings were discarded

1. **Failure.** Recording only sustain-pedal or other controller movement produced no clip and no undo step. A pedal-only overdub therefore lost its captured performance at Stop.
2. **Mechanism.** `crates/engine/src/midi_take.rs::build_wrapping` collected channel messages into `Sequence::ctrls`, then skipped every sequence whose notes were empty. Retention now checks both notes and controller events.
3. **Why checks missed it.** Two lower-level `midi_take` fixtures and `midi_record_tests::stop_during_the_count_in_or_with_nothing_played_records_nothing` explicitly expected a pedal-only pass to disappear. That conflated no captured events with no notes. It now checks a truly empty capture; a separate host Stop regression checks controller-only capture.
4. **Regression tests.** `crates/engine/tests/cc_lanes.rs::controller_only_recording_overdubs_and_undo_preserves_the_existing_notes` drives recording placement, validates original ticks/channel/values, session round-trip, and undo/redo. `crates/ui-studio/src/midi_record_tests.rs::controller_only_capture_reaches_the_clip_through_host_stop_and_is_undoable` drives the host Stop handler with captured pedal events. Both must fail at runtime with the old notes-only emptiness predicate. Both negative proofs failed at runtime: placement returned no clip, and host Stop produced zero clips instead of one. After each probe, the retention fix was restored. The updated lower-level retention fixture also failed with the old predicate. The separate recorded-sustain test checks disk save/open and bit-identical audio playback.
5. **Gate class.** MIDI recording retention must be tested with controller-only as well as note-bearing captures. An empty-performance predicate must account for every event collection that recording preserves.
6. **Protocol change, owner, blind spot.** The MIDI recording row in `docs/contributing/evidence/gates.md` requires controller-only retention coverage for capture, construction and placement changes. Owner: MIDI recording maintainers. These hermetic tests cover captured-event-to-clip placement, undo, storage and offline playback; physical device timing and live hardware output remain outside this gate.
