Cycle recording does not carry a held pedal across the loop seam (#94, low): the take built per lap starts each lap with the pedal up, so a pedal held through the seam is recorded as a release and re-press only if the performer lifts it. Held notes do carry across the seam; playback of a looped clip is unaffected.
