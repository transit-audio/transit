Native JACK (ADR 0021): a server quantum or rate change reopens the device (the transport stops; a take is kept). Under PipeWire's JACK library that happens when another program forces a quantum, when a forcing client leaves, when the node moves to another driver or when the driver resumes; PipeWire does not change the quantum just because another client asks for a smaller one, since every JACK client locks the quantum by default and only a forced quantum overrides the lock (#760, ADR 0021 amendment, rule 7). The code also reads the rate and buffer size before the client is active, so a graph running at other than that figure (`PIPEWIRE_LATENCY`, a non-default quantum) may reopen the device after the first start; this is tracked in #760 and not yet confirmed on a PipeWire machine.
