A dialog can open behind a plug-in editor window (Windows). Plug-in editors are separate windows that the dimmed background of a modal dialog cannot cover yet, so a dialog opened while an editor is in front can be hidden behind it. Making transit's dialogs real windows that come to the front is planned as its own design (#770).
