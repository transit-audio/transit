A file dragged in from the file manager has no drop position on any platform: winit 0.30 reports `DroppedFile(PathBuf)` alone (the Windows drop handler ignores the OLE `POINTL`), and no cursor motion arrives during the OS drag, so egui's pointer is stale or gone when the drop lands. On Windows transit asks the OS for the cursor position at the drop's frame and routes the drop there (on hardware the pointer's next report did not come first: a `PointerGone` did, and the drop went to the arrangement). Other platforms still hold the drop until the pointer's next report and route it there; a `PointerGone` keeps it held, and after 30 frames with no position it goes to the arrangement (#368).
