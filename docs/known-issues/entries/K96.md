Racks ([ADR 0034](../../adr/0034-racks-layering-instruments-through-track-groups.md), #197): a member removed from its rack (or moved out of the rack's folder) while it holds a live note from the rack keeps that note when a render worker held the member's strip at the moment the note came: the engine did not record which port the rack played it from, so leaving the rack does not release it. A seek or Stop releases only clip notes, so the note sounds until the port is revoked (unplugged) or a panic. The rack's clip notes and every other live note are released when the member leaves.
