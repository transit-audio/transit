On macOS a heavy plug-in's create call blocks the UI thread for its duration: AppKit wants editors on the process main thread, so hosted instances are created inline there (`INLINE_BY_DEFAULT` in `crates/plugin-host/src/lib.rs`). On every platform, offline renders (bounce, stems, freeze) make their instances on the thread that builds the render ([ADR 0018](../../adr/0018-plugin-host-thread.md) says why). Windows and Linux create, restore, edit and destroy hosted instances on the plug-in host thread.
