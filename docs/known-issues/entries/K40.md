A session with a looped clip ([ADR 0019](../../adr/0019-clip-internal-loops.md)) that an older build opens and saves loses the loop (the unknown field is dropped); builds from the `needs` marker on warn on load about features they do not know, the ones before it cannot, leaving a long clip that is silent past its source. Since ADR 0019's Amendment 2026-11-09 a MIDI loop cycle is a whole number of ticks, so a tempo change inside a looped MIDI clip keeps later cycles at their musical positions; audio loops still repeat a whole-sample cycle (#427). A tempo change that would squeeze a loop under 64 samples is refused, naming the clip.
