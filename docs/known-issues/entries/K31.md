Verify the ASIO loop per driver. Calibration over native ASIO measures the loop by sample position; the driver's `getLatencies` figures are shown beside it. By sample position they agree with the measured loop within 1-5 frames on the Scarlett 2i2 at 48 kHz (64: 333 vs 328; 128: 647 vs 648; 256: 1196 vs 1192; 512: 2188 vs 2184; the earlier sign-flipping error was an arrival-time artifact, see the correction on [the 2026-10-23 benchmark](../../benchmarks/2026-10-23-ryzen-5900x-scarlett-2i2-asio-reported-vs-measured.md)), so without a Measure placement there is already within about 5 frames. Unverified at 44.1 kHz and on other drivers; the Model 12's loop can come up a buffer apart between starts.
