Load Kit Folder holds the interface while it decodes (#450). After the choice is made (Load kit, Replace or Fill free pads), the folder's files are read and decoded before transit answers again; a large folder or a slow drive keeps the window unresponsive for that time. Nothing is lost: the load is still one undo step and a refusal still changes nothing. Kit preset recall waits the same way.
