The native ASIO watchdog runs on the host thread between requests, so while a driver call holds that thread (the driver's settings panel, a stuck request) a driver that stopped calling is not caught until the call returns; a stall whose last buffer switch still holds the engine flag is delivered when it lets go. The Player's own output stall check (2 s while playing) still applies.
