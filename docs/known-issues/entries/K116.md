macOS: CLAP editors that offer only an embedded Cocoa view (JUCE-built ones such as CHOW Tape) failed with "cocoa embedding not supported (neither)": the CLAP host embedded editors on Windows and Linux only. They now open in the same `NSWindow` the VST3 host uses (moved to `transit_rt::editor_window`). As on Linux (K94), that window has no header strip (presets, Save, Bypass, the menu and MIDI Learn: use the device card and the mixer), is not user-resizable, and follows the plug-in's own resize requests only.
