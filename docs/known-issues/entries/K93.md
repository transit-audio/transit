Linux editor windows (#147), scale: the editor's scale comes from the desktop's one `Xft.dpi` (else the screen's size in millimeters), so on monitors with different scaling an editor keeps the scale it opened with, and the window does not rescale when moved between them; X11 has no per-monitor DPI. A change of the desktop's scaling setting reaches open editors (`Xft.dpi` changes). Under XWayland with fractional scaling the compositor may scale the whole editor window, which blurs it.
