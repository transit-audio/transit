Clip group files tagged `soundcraft.clipgroup` and track presets tagged `soundcraft-track-preset` (written before v0.7.0) read in v0.7.x only. v0.7.x reads them, tells the caller once per read (the status line and the command result's `note`: "<name>: saved before transit 0.7.0; ... to keep it opening in 0.8.0 and later"), and writes `transit.clipgroup` (`.tclips`) and `transit-track-preset` (`.tpreset`); from the **v0.8.0 tag** they are refused with "This file was saved by a version before transit 0.7.0. Open and save it in transit 0.7.0 first: https://github.com/transit-audio/transit/releases/tag/v0.7.0" ([ADR 0049](../../adr/0049-inherited-file-identifiers-retire.md)). Files written by v0.7.0 do not open in v0.6.x. On Linux the session MIME type is now `application/x-transit-session`, so a hand-set per-user default app for `.transit` files is set once more.
