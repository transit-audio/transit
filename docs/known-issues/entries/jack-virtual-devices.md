Native JACK, **Show virtual devices** (#431): the Input list can offer an application's stream, a sink's monitor or a virtual source as the input. The classification is the server's hardware flag only; transit guesses nothing from names except the existing monitor label. An application playing several streams shows as one device whose ports can change between opens; paths over changed ports stay off until the original ports return or the user presses **Use the current ports** while stopped.
