A plug-in editor that neither takes the host's scale (VST3 `IPlugViewContentScaleSupport`, CLAP `set_scale`) nor reads the monitor's DPI itself draws at 100% on a scaled Windows display, small in a window sized to it (#101). A VST3 plug-in that applies the factor only once attached gets it again after `attached` and its `resizeView` is honored (#105); the info log shows, per plug-in, whether the interface was found, the factor's result, and each resize. The host applies no bitmap stretch, by design, so self-scaling plug-ins are never scaled twice.
