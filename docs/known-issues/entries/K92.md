Linux editor focus and keyboard (#147, #289): the host speaks a version 0 XEmbed subset (activation, logical focus, click REQUEST_FOCUS and key press and release forwarding) for editor children it had to map itself. Editors that map their own window keep direct keyboard focus even when they advertise `_XEMBED_INFO`. XWayland focus still depends on the compositor. Not implemented: accelerator registration, tab traversal, modality, drag and drop, and forwarding keys the plug-in does not use back to transit.
