Linux editor focus and keyboard (#147, #289): XEmbed activation, logical focus, click REQUEST_FOCUS and key press/release forwarding are now supported. Editors that map their own window retain direct keyboard focus even when they advertise `_XEMBED_INFO`; the XEmbed path applies only to children the host had to map. XWayland focus still depends on the compositor. Accelerator registration, tab traversal, modality and forwarding unused keys to transit are not implemented.
