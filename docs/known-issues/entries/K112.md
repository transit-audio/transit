Opus export is mono and stereo only (#238): a surround main mix, bus or output path bounced as Opus is refused with "transit writes mono and stereo Opus only; fold the bounce down to stereo, or bounce WAV or FLAC". Surround Opus needs channel mapping family 1 (Vorbis channel order) and libopus's multistream encoder; the import side reads mono and stereo Opus files and refuses other mapping families the same way.
