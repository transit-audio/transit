A hardware insert on a mono strip takes only the first return channel; a stereo strip with a mono send sends the channel average. Offline paths (bounce, freeze, stems) have no live input, so the insert prints dry with no warning. An unmeasured pair runs with 0 latency and arrives late by the round trip.
