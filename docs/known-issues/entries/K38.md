Closed: a VST3 module entry (`InitDll`, `bundleEntry`, `ModuleEntry`) that never returned held the VST3 loaded-module lock (`Bundle::load`), so every later VST3 load blocked on it and wedged the next host thread too. Modules are now entered outside the lock (a per-binary loading marker); a hung entry holds back loads of its own binary only. Both hosts also build a type's description (its parameter table) outside the registry lock.
