MIDI Learn (#97): a move of a hosted parameter is applied only once the plug-in's parameter table is in the host's cache, which any instance of that plug-in fills when it loads (a project's plug-ins load on open); a mapping to a plug-in that has not loaded yet, or never loads, is stored and ignored (the first move of a sweep says so in the status line and the log).
