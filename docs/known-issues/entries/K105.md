With the tail off, compilation still charges the tail graph and input snapshots against `prepared_bytes` (the added charge depends on the topology: it grows with the block size, the channel count and the number of aux readers), so a plan close to the 1 GiB default limit that an earlier build admitted can be rejected with a `ResourceLimit` on `prepared_bytes`; the limits are unchanged. One example that crosses the default is 900 stereo auxes at a 16384-frame block; it is not the only case.
