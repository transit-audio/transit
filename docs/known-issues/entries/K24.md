Native WASAPI shared mode on the Focusrite Scarlett 2i2 measures a round trip of about 248 ms (219 ms in stamp time, +-2.9 ms), the same through cpal's WASAPI backend, so it is the driver's shared-mode path and not usable for tracking on this device; the input xruns both backends reported (63 and 25 in a 10 s run) were the callback-gap heuristic (K26) and read 0 with the drift detector.
