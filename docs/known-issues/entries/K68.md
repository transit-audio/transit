MIDI feedback protection (#99): the "muted: feedback storm detected" note shows in the track's MIDI input menu, the External Instrument card and (as "echo off") the arranger chip, but not in the MIDI Monitor's port header. The same-device name rule treats the ports of one multiport interface as one device ("MIDIIN2 (ESI M4U)" and "MIDIOUT4 (ESI M4U)", "MIDI In 2" and "MIDI Out 1", named loopMIDI pairs), so a keyboard on one port playing a synth on another port of that interface needs the echo opt-in; WinMM ids are compared up to their class suffix without a hardware check. On an opted-in self-echo port, a performer repeating one non-NRPN message faster than 250 a second (a relative encoder) cannot be told from a loop and mutes it. A loop slower than a 4 ms round trip carrying only a few messages stays under both bounds.
