MIDI Learn (#97): a plug-in toggle or choice parameter follows the knob's position (it flips as the knob crosses half travel or a step); a plug-in parameter is never a button, so there is no press-to-toggle for it (a mapped mute, solo or record arm does toggle). The mappings window labels a plug-in target by slot and parameter id ("Insert A cutoff"), not the display name.
