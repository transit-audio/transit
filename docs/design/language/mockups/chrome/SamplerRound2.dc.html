10Edge fades on the key map Drawn, not dragged, in 0.7.0: a fade is a wedge inside the zone edge, the zone's fill running to 25% across the fade's keys (or velocities). The values are set in the Zone panel (four fields: key low, key high, vel low, vel high). Dragging a fade on the map waits.
