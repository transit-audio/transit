TRANSIT · LIGHT THEME · DRAFT 1

Designed, not mirrored

The derived set kept every ink at its dark contrast ratio, which pushed mod to brown and meter.ok to forest green, so the colours stopped meaning what they mean. This set keeps the roles and the hues, and sets targets instead: text ≥ 4.5:1, marks ≥ 3:1, and every accent pair ≥ ΔE 20 for normal, protan, deutan and tritan vision.

01 Panels are cards The window is mid-light graphite; panels sit lighter on it, raised controls are white. Up is lighter, as in dark.
02 Wells recess Display wells and value fields go one step darker than the panel, not white, so a well still reads as a screen set into the panel.
03 Orange, not brown Mod is a true orange (#E17000), not a dark amber that reads brown. It draws rings, traces, dots and amount bars (3:1 on panels), never body text.
04 Red moves deeper On white, orange and red collapse for deutan vision (ΔE 6). A golden amber and a deep red keep them apart (ΔE 20+).

The new light rule Same roles, same hues. Grounds: window mid-light, panels lighter, raised white, wells one step darker than the panel. Inks: text ≥ 4.5:1 on panel and inset; marks ≥ 3:1; ink on a filled role (solo, arm, cycle, default button) is the light ground. Accents ≥ ΔE 20 from each other under normal, protan, deutan and tritan vision. Clip and track colours stay as chosen.
