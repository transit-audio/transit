01 A button and an off toggle look the same Both are surface.raised with a 1 px line. Which one latches?
AS BUILT
Only case and a 1 px radius tell them apart.
PROPOSED
A button has no border. If it's outlined, it latches.
Alternative if you'd rather keep the border on buttons: drop it from toggles instead. That would mean changing the device spec, which has already landed, so I'd change the chrome side.
