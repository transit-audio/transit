Sixteen hues evenly spaced in OKLCH (22.5° apart, starting at 11°, the rotation that keeps every swatch furthest from the five accents), each with a strong value for bars and tags, a body for clip fills and a darker or deeper strip for clip names. The same names in both themes; the user picks a name, the theme supplies the value.

Is 16 enough? Yes, as hues. Neighbours are only ΔE₂₀₀₀ 8.6 apart already: tellable side by side, not reliably across a screen on a 3 px bar. More hues would add swatches people cannot tell apart. Ableton's 70 are about 14 hues in 5 brightnesses. If tracks ever need more, add a second, muted brightness row of the same 16 hues; choke groups stay at 16, one per group number.
Content, not signal With 16 hues round the wheel some swatch always sits near an accent (best rotation: ΔE 5). So palette colours are calmer than accents (OKLCH chroma 0.13 against signal's 0.16) and only ever fill: track bars, clip bodies and strips, choke tags. They never draw a ring, arc, outline, curve or meter.
